Let’s get you connected.

Start with the setup guide, or find the part that isn’t working below.

The Mac isn’t reachable

Keep the Mac awake and signed in, open TailView Mac, and choose Start sharing or Resume Access. Verify that Tailscale is connected on both devices and the address in iOS matches the address shown by TailView Mac. If you manage network rules, allow TCP 47820 between those devices. Do not expose the port directly to the internet.

If TailView reports that the Tailscale CLI is unavailable, install the current Tailscale Mac app and follow its command-line setup instructions, then reopen TailView. If your VPN or managed network prevents the connection, check with its administrator.

I see a blank screen, or cannot click and type

Allow TailView Mac in macOS System Settings → Privacy & Security → Screen Recording (called Screen & System Audio Recording on some versions). For mouse and keyboard control, enable Allow paired devices to control this Mac in TailView and grant macOS Accessibility permission. Quit and reopen the app if macOS requests it. Keep a single current copy in Applications so the permission belongs to the app you are actually running.

The code expired, or a saved device is rejected

Open Pair a new device on the Mac and use the new code within five minutes. Each code permits one successful pairing. A revoked device needs a new pairing; removing and restoring the iOS purchase does not restore Mac access. Never post a pairing code in a support issue.

Mac sound works, but the Mac app cannot hear my voice

Enable Mic on iOS, allow Microphone access in iOS Settings, and make this device the audio owner in TailView’s audio settings. Install BlackHole 2ch separately on the Mac and select it as the receiving app’s input. The Mac host shows the route it is using. Its automatic microphone-routing setting is optional and off by default; enable it only if you want TailView to change the Mac’s default input during a session. An orange microphone status means capture is not currently sending even if the toggle is on.

Only one connected device owns audio at a time. A microphone used by another app, a phone call, or a route change can interrupt it; bring TailView to the foreground and toggle Mic to retry.

Lock-screen controls or background audio stopped

iOS can suspend a viewer without active audio. Open TailView again to reconnect. Lock-screen controls show only while a session can keep running; they are not a guarantee that the Mac is reachable. A long network outage pauses background recovery until you open the app.

My Mac display is dark or its local keyboard is blocked

From a connected viewer, choose Restore Display Backlight or Reconnect Built-In Display in the Mac host. Quitting TailView normally also restores the display. If access is lost, restarting the Mac is the fallback.

Display darkening and disconnection are advanced controls that use undocumented macOS interfaces and may stop working after an OS update. If you enabled local-input blocking, there is no physical-keyboard escape while it is active. A dark display does not lock the Mac; do not use it as a replacement for macOS security.

How does the seven-day trial work?

You explicitly start the free 7-day Trial through Apple’s purchase sheet. It is a non-consumable in-app purchase, not a subscription. Seven days after the original trial transaction, remote viewing, control, and audio require the lifetime unlock. There is no automatic charge and nothing to cancel. Reinstalling or restoring does not restart an expired trial.

The planned US lifetime price is $9.99. Apple’s purchase sheet shows the actual local price. One lifetime purchase unlocks the iOS app on your devices using the same purchasing Apple Account; it does not promise compatibility with every future OS or the continued availability of third-party services.

I bought TailView, but it is asking me to unlock again

Use Restore Purchases in the app with the same Apple Account that bought the lifetime unlock. An internet connection may be needed to restore. If Apple shows a pending purchase, finish the approval or checkout before retrying. A refunded or revoked purchase no longer grants access. For billing or refund help, use Apple’s purchase support.

Still stuck?

Open a support issue

Include the Mac and iOS app versions, macOS and iOS versions, device models, the action you tried, the exact error with private details removed, and whether other Tailscale connections work.

GitHub issues are public. Do not include pairing codes, credentials, private addresses, personal screen contents, payment information, or raw logs. Ask for a private contact route before sharing anything sensitive.

Source code and existing issues are on GitHub. For how the apps handle your information, read the privacy policy.
